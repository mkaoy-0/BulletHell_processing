## 動作に必要な外部素材について

著作権・ライセンス保護のため、BGMおよびフォントファイルは本リポジトリに含まれておりません。  
実行する際は、以下の素材を入手して `data/` フォルダを作成し、その中に配置してください。

### BGMファイル
1. **配置先:** `data/kagurauta.mp3`
 - **入手先:** DOVA-SYNDROME（曲名：[神楽謡](https://opentracks.com/bgm/detail/4193) / 作曲者：まんぼう二等兵 様）

2. **配置先:** `data/kazekiri.mp3`
 - **入手先:** DOVA-SYNDROME（曲名：[風切](https://opentracks.com/bgm/detail/6917) / 作曲者：ゆうり(Yuli Audio Craft) 様）

3. **配置先:** `data/Starting_Point.mp3`
 - **入手先:** DOVA-SYNDROME（曲名：[Starting Point](https://opentracks.com/bgm/detail/10350) / 作曲者：FLASH☆BEAT 様）

### ライブラリ
Minim（※実行前にライブラリマネージャーから追加してください）


## 使用環境
- Processing 3.5.4
- Processing 4.3
